# 同行足迹 · 微信小程序模板

一个基于微信云开发的社群成长记录与互动小程序模板，适用于学校、社团、公益组织、兴趣小组与活动社区。

> 本仓库是由实际项目整理出的通用模板。品牌、活动分类、演示文案与素材均可替换；真实用户数据、私有配置、云环境标识及支付密钥不包含在仓库中。

## 功能概览

- 多活动、多阶段的成长足迹：首页分类与自定义活动均支持伙伴、相册、记录和作品。
- 相册体系：可新建多个相册、设置名称与封面，再向指定相册上传照片。
- 公开动态：汇总公开相册、记录和作品，支持时间榜单、热度、点赞、评论与回复。
- 好友关系：通过 7 位 UID 添加好友，查看好友授权的足迹与简介，并进行聊天。
- 个人资料：头像裁切、昵称、简介、标签、成长年限与活动经历。
- 收藏、图片预览与下载、作品文件打开、举报、内容安全检查。
- 背包与赠礼：好感等级、收礼统计、信封/纪念册留言及多种示例道具。
- 任务、奖励邮箱、排行榜奖励、管理员福利发放与到期清理。
- 可选虚拟支付：服务端下单、支付回调、主动查单、幂等发货与退款审计。
- 隐私与治理：用户协议、隐私摘要、社区规范、反馈与账号注销申请。

完整功能树见 [功能总览与思维导图](./docs/小程序功能总览与思维导图.md)。

## 技术结构

- 微信小程序原生框架：WXML / WXSS / JavaScript
- 微信云开发：云函数、云数据库、云存储
- 单一业务云函数：`cloudfunctions/hui-api`
- 客户端云端适配层：`utils/cloud-service.js`
- 本地预览与云端数据适配：`utils/data.js`

目录说明：

```text
├─ assets/                    示例图片与图标
├─ cloudfunctions/hui-api/    身份、内容、好友、奖励与支付服务
├─ components/                页面导航、场景横幅、头像裁切等组件
├─ config/app-config.js       品牌、云环境与存储前缀配置
├─ data/mock-data.js          活动分类与本地演示数据
├─ pages/                     小程序页面
├─ utils/                     数据、上传、隐私与道具工具
├─ CLOUD_SETUP.md             云开发部署步骤
└─ VIRTUAL_PAYMENT_SETUP.md   可选虚拟支付接入说明
```

## 快速开始

1. 克隆仓库，用微信开发者工具导入项目根目录。
2. 在 `project.config.json` 中将 `touristappid` 替换为自己的小程序 AppID。
3. 创建或选择自己的云开发环境，在 `config/app-config.js` 填写 `cloudEnvId`。
4. 按 [CLOUD_SETUP.md](./CLOUD_SETUP.md) 创建数据库集合，并部署 `hui-api` 云函数。
5. 在微信公众平台按实际功能完善隐私保护指引和用户生成内容场景声明。
6. 使用两个不同微信账号完成资料、好友、公开内容、图片上传与权限回归测试。

只想预览界面时，可以先保留 `touristappid`；好友、跨设备内容、云存储和奖励等功能需要真实 AppID 与云环境。

## 个性化入口

- 品牌名、云环境、函数名、存储目录：`config/app-config.js`
- 活动名称与阶段文案：`data/mock-data.js`
- 首页场景图：`assets/images/`
- 主题颜色与通用样式：`app.wxss`
- 关于模板折叠页：`pages/profile/developer.js`

内部字段 `campId`、云函数目录名 `hui-api` 和数据库前缀 `hui_` 为兼容原业务数据而保留，不影响界面通用化。全新项目可以在充分测试后统一重命名，但应同时修改前端调用、云函数配置和已有数据迁移逻辑。

## 安全提示

- 不要把 AppSecret、支付 AppKey、管理员 OPENID 或真实 `.env` 文件提交到 Git。
- 支付参数只能放在云函数环境变量中；公开仓库中的 `.env.example` 只列变量名。
- 管理员权限必须绑定 OPENID 或服务端 `isAdmin` 字段，不能仅凭公开 UID 判断。
- 上线前替换或确认示例素材的使用权，并清空演示数据。
- 如果任何密钥曾出现在聊天、截图、日志或历史提交中，应先在微信公众平台轮换。

## 虚拟支付

虚拟支付是可选模块。未完成主体资质、商品配置、回调订阅和沙箱/现网验收时，请隐藏商店入口。配置方法见 [VIRTUAL_PAYMENT_SETUP.md](./VIRTUAL_PAYMENT_SETUP.md)。
