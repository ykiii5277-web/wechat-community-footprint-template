# 同行足迹 · 微信小程序模板

基于原生微信小程序与微信云开发的社群成长记录模板，适用于学校、社团、公益组织、兴趣小组和活动社区。此次按当前应用代码完整更新，包含视频、好友分组、作品审核、通知、分包及同步优化。

仓库保留通用品牌、可替换活动分类和空白用户数据，不包含原应用的 AppID、云环境、管理员身份、登录凭据或业务数据。使用者需要部署自己的环境并完成真机验收。

## 功能

| 模块 | 当前能力 |
| --- | --- |
| 首次使用 | 必须完善昵称与简介，保存后开始九步引导，可跳过、重看 |
| 趣闻 | 公开内容、最新和周期热榜、筛选、五按钮分页、详情连续浏览 |
| 足迹 | 多活动、多阶段；伙伴、相册、记录、作品；自定义活动 |
| 相册 | 必填名称、图片自动命名、连续多选、全选、批量删除/移动/范围和隐藏 UID |
| 图片 | 全屏切换、双指缩放与拖动、保存，退出后保持当前图片 |
| 记录与作品 | 记录最多9张图片；作品支持视频压缩、播放、保存和文档附件 |
| 好友 | 7位 UID、申请附言、聊天、授权内容、分组管理、三种排序 |
| 互动奖励 | 点赞、评论回复、收藏、背包赠礼、好感度、任务、热榜奖励、邮箱 |
| 审核管理 | 待审核提示、公开非图片附件审核、驳回原因邮件、自动退回私密、福利和账号删除 |
| 同步权限 | 云端确认、账号隔离、失败重试/取消、跨设备恢复、服务端访问控制 |

当前版本没有商店或虚拟支付，不需要支付密钥、支付集合和支付触发器。

## 快速开始

1. 克隆仓库，用微信开发者工具导入根目录。
2. 在 `project.config.json` 把 `touristappid` 替换为自己的 AppID。
3. 创建云开发环境，在 `config/app-config.js` 填写 `cloudEnvId`。
4. 按 [部署指南](CLOUD_SETUP.md) 创建16个集合、配置权限与索引。
5. 部署完整的 `cloudfunctions/hui-api`，安装依赖与两个定时触发器。
6. 设置管理员，完善平台声明，用两个微信账号完成真机验证。

当前模板要求首次登录连接云端并完善简介。未配置真实 AppID 和环境时，游客模式或静态预览不能作为可用的离线产品。

## 项目结构

```text
app.js / app.json             启动、登录门禁、引导与分包
config/app-config.js          品牌、云环境、函数名、上传目录
config/database-indexes.json  集合与索引配置清单
cloudfunctions/hui-api/       身份、内容、权限、审核、好友、奖励
components/                  导航、评论、引导、头像裁切等组件
custom-tab-bar/              四栏导航与好友/审核提示
data/mock-data.js            可替换活动分类，用户内容为空
packages/camps/              营地与好友营地分包
pages/                       页面，相册/记录等采用分包
utils/                       通信、账号缓存、同步、媒体、分页
styles/                      自己与好友页面共用的卡片样式
scripts/ / tests/            静态检查与隔离回归测试
```

## 配置与文件限制

云环境、函数名与新文件上传前缀在 `config/app-config.js` 配置。活动名称与阶段见 `data/mock-data.js`，主题见 `app.wxss`。`brandName` 用于应用全局信息，页面内的品牌文案也应同步替换。

内部 `hui_` 集合前缀、`hui-api` 目录、兼容路由和 `hui_time_` 缓存键继续保留。已有数据上线后不要直接重命名内部活动 ID 和字段。

单张图片上限20MiB，视频压缩后500MiB，其他作品文件1000MiB。相册可连续追加，选择器单次数量受微信能力限制，记录总数仍限制9张。单文件限制与云环境套餐总容量不同。

前端和云函数需要配套更新。上传小程序不会自动部署云函数、创建索引、安装触发器或修改微信公众平台声明。

## 自动检查

Node.js 18以上，无需安装根目录依赖。

```bash
npm run check
npm test
```

检查覆盖路由分包、账号隔离、上传、审核权限、驳回通知、同步、好友、并发幂等、奖励和图片预览。使用隔离内存数据库与微信 API 模拟，不连接真实云环境，不替代真机和平台配置验收。
