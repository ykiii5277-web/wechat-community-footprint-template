# 初学者阅读指南

如果你第一次接触微信小程序，可以按这个顺序阅读项目：

1. `app.json`：查看页面清单和四个底部栏目。
2. `data/mock-data.js`：修改活动分类、阶段名称与演示内容。
3. `config/app-config.js`：修改品牌名、云环境 ID 与存储目录。
4. `pages/`：每个文件夹通常是一组页面，`.wxml` 是结构、`.wxss` 是样式、`.js` 是交互。
5. `utils/data.js`：本地数据与云端数据的统一适配层。
6. `utils/cloud-service.js`：前端调用云函数、上传图片和解析云文件的入口。
7. `cloudfunctions/hui-api/index.js`：多用户、好友、互动、奖励与支付等服务端规则。

建议先只替换品牌、活动名称和图片，在开发者工具里确认页面正常；再按 `CLOUD_SETUP.md` 接入自己的云环境。不要把真实 AppSecret、支付 AppKey 或管理员 OPENID 写进源代码。

常见问题：

- 只能本机看到内容：尚未部署云函数，或保存了临时文件路径。
- 图片无法选择：公众平台的隐私保护指引尚未发布，或未声明照片/摄像头用途。
- 图片上传失败：`config/app-config.js` 的云环境 ID、云存储权限或配额有问题。
- 好友和动态没有跨账号数据：云函数未部署，或数据库集合未创建。
- 支付按钮不可用：支付是可选能力，必须完成平台资质和云函数环境变量配置。
